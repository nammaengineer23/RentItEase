# RentItEase User Guide

## Tenants

1. Create an account with email/password, Google sign-in, or supported phone verification.
2. Search by locality, city, or property name; apply available filters.
3. Open a listing to view rent, amenities, photos, owner status, location, and reviews.
4. Save a listing to Favorites or start a chat with the owner.
5. Request a visit, wait for owner approval, then create a booking when eligible.
6. Complete payment only through the displayed payment flow; retain the invoice.
7. Create and review a lease only after a paid booking.

## Property owners

1. Complete your profile and create a property listing with accurate rent, description, photos, amenities, and location.
2. Accept the consent request before submitting the listing.
3. A new property remains pending until an administrator approves it; it is not publicly visible beforehand.
4. Manage visits, bookings, chats, property edits, images, and listing status from the owner area.
5. Use Analytics to review properties, views, favourites, and visits.

## Safety

Never share OTPs, passwords, or card details in chat. Verify a property in person before making rental decisions.
