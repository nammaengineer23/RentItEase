# RentItEase Admin Guide

## Daily moderation

- Review owner verification requests.
- Approve or reject pending properties after checking title, price, location, photos, and content.
- Review reported or inappropriate listings, reviews, and users.
- Monitor pending visits, booking activity, payment records, invoices, and memberships.

## Visibility rule

Only approved, active properties are eligible for tenant discovery. Rejected or pending listings must remain unavailable in public search.

## Reporting

Use the Admin dashboard for users, properties, visits, reviews, billing, and analytics. Treat dashboard totals as operational data; investigate material discrepancies before taking action.

## Support escalation

Record the user ID, property/booking/payment ID, timestamp, and screenshots. Do not request passwords, OTPs, or payment secrets.
